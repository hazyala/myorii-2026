# macOS DMG 배포와 첫 실행 준비

## 빌드

프로젝트의 가상 환경에서 `python scripts/build_dmg.py`를 실행한다. 검은 묘리 원본(`assets/characters/myorii_profile.png`)으로 ICNS를 만들고 PyInstaller로 Python·Qt·인증서·리소스를 포함한 앱을 빌드한다. `dist/Myorii-macOS-arm64.dmg`와 SHA-256 파일이 생성된다. Intel Mac에서는 해당 아키텍처의 Python과 의존성으로 별도 빌드하며 파일명은 x86_64가 된다. 빌드 결과는 Git에 넣지 않는다.

DMG에는 Myorii.app, Applications 바로가기, 설치 안내가 들어간다. 웹 다운로드 링크로 배포할 수 있으며 로컬 추론용 서버를 운영할 필요는 없다. 현재 결과물은 ad-hoc 서명만 있는 테스트 배포본으로 Developer ID 서명·공증은 포함하지 않는다. Gatekeeper를 해제하거나 다운로드 격리 속성을 제거하는 동작은 없다. 다른 Mac의 첫 실행 허용은 사용자가 macOS 안내에 따라 결정해야 한다.

## 첫 실행

앱은 로컬 제공자의 선택 모델을 확인한다. 기본값은 `qwen3-vl:4b-instruct`(약 3.3GB)다. 서버가 응답하고 모델이 있으면 바로 메인 화면을 연다. 준비가 필요하면 검은 묘리 이미지, 필요한 다운로드 안내, 시작·나중에·취소 버튼을 표시한다. API 제공자가 설정되어 있으면 로컬 준비를 건너뛴다.

시작 버튼 이후 진행 순서:

1. 기존 Ollama 서버, `/Applications/Ollama.app`, `~/Applications/Ollama.app`, PATH의 CLI를 확인한다.
2. 설치가 없으면 공식 HTTPS 주소에서 DMG를 임시 다운로드한다. 앱의 Apple 서명과 Ollama 배포자 Team ID를 검사한다. 실패하면 실행하거나 설치하지 않는다.
3. 검증된 앱을 사용자 `~/Applications/Ollama.app`에 임시 복사 후 이동한다. 기존 설치를 덮어쓰지 않는다. 디스크 이미지는 해제하고 임시 파일을 정리한다.
4. Ollama 앱을 실행하고 응답을 기다린다. macOS 실행 승인 창은 사용자에게 안내한다. CLI 전용 설치는 `serve`를 실행한다.
5. 모델이 없으면 `/api/pull` 스트림으로 다운로드량과 레이어 진행률을 표시한다. 성공 이벤트와 실제 모델 목록을 모두 확인한다.
6. 모델을 실제 로딩해 메모리·실행 오류를 확인한 뒤 메인 화면으로 이동한다.

실패하면 오류와 재시도를 표시한다. 취소는 읽기·하위 프로세스 경계에서 처리하며 다운로드 연결은 최대 30초, 모델 로딩 연결은 최대 120초 기다릴 수 있다. Ollama 모델의 부분 다운로드는 재시도에 재사용한다. 취소 시 기존 설치·모델을 삭제하지 않는다. API 사용 / 나중에는 준비를 생략하고 앱 설정에서 제공자를 선택할 수 있게 한다. 로컬 준비가 안 된 상태로 다시 실행하면 안내가 다시 나온다.

## 검증 범위

2026-10-15: 자동 회귀 테스트 81개 통과. 기존 설치·모델 재사용, 미설치 흐름, 중단된 스트림, 다운로드 오류, 모델 로딩 실패, 취소 시 하위 프로세스 종료, 서명 불일치 시 설치 차단, 수 GB 진행률, UI 재시도를 검증했다.

실제 공식 Ollama DMG를 내려받아 별도 임시 폴더에 서명 검사·설치 후 CLI 실행을 확인했다. 사용자 설치와 모델은 변경하지 않았다. macOS 실제 준비 화면에서 검은 묘리 이미지·안내·버튼 배치를 확인했다. DMG 파일 무결성과 내부 앱 서명을 확인하고 DMG에서 복사한 앱 실행과 실제 채팅 응답을 확인했다.

별도 포트의 Ollama 서버와 빈 임시 모델 저장소에서 Qwen 약 3.3GB 전체 다운로드, 성공 이벤트, 모델 목록, 실제 모델 로딩을 확인했다. 테스트 서버를 종료하고 임시 저장소를 정리했다. 결과 요약은 `tests/results/dmg-setup-2026-10-15.json`에 기록한다.

이 Mac에서 검증한 빌드는 Apple Silicon용이다. 완전히 새 macOS 계정·별도 Mac의 Gatekeeper 승인 화면과 Intel 하드웨어는 별도 환경이 없어 검증하지 않았다.

### 첫 실행 화면 보완

2026-10-15 사용자 제보: 첫 표시에서 바탕화면이 비치고 사각 테두리가 드러나다 다시 열면 달라지는 현상. 팝오버 본문을 불투명하게 그리고 전체 그림자 효과 및 showEvent의 스타일 재적용을 제거했다. 라이트·다크의 첫 표시/재표시 이미지 일치, 본문 알파 255, 외곽 모서리 알파 0을 회귀 테스트로 검증했다. 전체 자동 테스트 82개 통과.

수정한 DMG에서 앱을 다시 복사해 첫 실행 화면을 직접 확인했다. 검증 후 해당 최신 설치본을 실행 상태로 유지했다.
