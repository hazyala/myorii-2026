묘리 설치

1. Myorii를 Applications 폴더로 드래그하세요.
2. 복사한 묘리를 실행하세요. 상단 메뉴바의 검은 묘리 아이콘으로 창을 열 수 있습니다.
3. 로컬 AI 준비 화면에서 준비 시작을 누르면, 필요한 Ollama와 Qwen 모델만 내려받습니다.
   기본 모델은 qwen3-vl:4b-instruct이며 약 3.3GB입니다.
   Ollama가 없다면 공식 배포 파일의 서명을 확인하고 ~/Applications에 설치합니다.
   macOS 확인 창이 나타나면 직접 확인해주세요.
4. API만 사용하려면 API 사용 / 나중에를 누르고 설정에서 제공자와 키를 선택하세요.

이 버전은 Apple Developer ID 서명·공증을 받지 않은 테스트 배포본입니다.
신뢰할 수 있는 배포처에서 받았는지 확인하세요. macOS가 개발자를 확인할 수 없다고
차단한 경우 시스템 설정 > 개인정보 보호 및 보안에서 앱 실행 허용 여부를 결정할 수 있습니다.
회사 관리 기기에서는 정책에 따라 실행이 제한될 수 있습니다.

로컬 AI: macOS 14 이상. Apple Silicon 권장. Intel은 별도 Intel 빌드가 필요합니다.
DMG 파일명의 arm64는 Apple Silicon용이며 x86_64는 Intel용입니다.
앱을 업데이트해도 사용자 대화·할일·메모와 기존 Ollama 모델은 유지됩니다.
다운로드 실패 시 재시도할 수 있습니다. 취소는 연결 종료를 기다릴 수 있습니다.
Ollama와 모델은 별도 구성요소로, 묘리 앱 삭제 시 함께 삭제되지 않습니다.
